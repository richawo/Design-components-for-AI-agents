Build one agent tool call as a single line in a flight recorder, in React 19 + Tailwind v4 + `motion/react`. It is a log entry, not a chat bubble: a mono tool name, a one-line argument summary, a live duration and a status glyph that morphs between queued, running, done and failed. Expanding the line shows the arguments as tinted JSON and the result, truncated. A failed line shows the stderr tail and a Retry. Dark first, monochrome, with one accent used only on a running arc and the argument tint.

**Code shape.** One file. Tokens (`PALETTE` written to `--ac-*` CSS variables, `RING_R`, `STALL_MS`), then sample calls keyed by tool name, then helpers (`formatDuration`, `summarise`, `highlightJson`, `useElapsed`), then `glyphVariants(reduce)` and `StatusGlyph`, then `AgentToolCall`, then the demo default export. The component owns its status when uncontrolled; a `status` prop makes it controlled. Every animation frame is cancelled on unmount.

**Layout.** `@container` root, full width of its column, `border-b` hairline at `--ac-line`. The header row is one `button` (full width, 10px radius, 12px horizontal padding): a two-digit index (`w-5`, mono 11px, ink at 30%, `aria-hidden`, hidden below a 384px container), the 16px status glyph, the tool name (mono 13px, weight 500, 12px in compact), a summary that truncates with an ellipsis (mono 12px, muted, `flex-1`), the duration (mono 12px, tabular figures, muted, right aligned), and a 14px chevron in the faint tone that rotates 180 degrees when open. Row padding is 14px top and bottom comfortable, 8px compact; a compact row grows to a 44px minimum on coarse pointers (`pointer-coarse:min-h-11`). Gaps are 12px. Below the header, the failure block (when failed) and the details panel (when expanded) both sit at a left inset of 72px (40px below a 384px container, where the index hides) so their content starts under the tool name. The failure block is a 10px-radius tinted box with 12px and 14px padding. The details panel is an argument block then a result block, 20px apart. Zero horizontal overflow: the summary truncates, and the JSON, stderr and result scroll inside their own boxes. A small `ScrollArea` measures each box: only when something is hidden does it become a focusable region with an `aria-label` (`Arguments`, `stderr`, `Result`) and the focus ring, and fade its right 24px with a mask until the reader scrolls to the end, so cut text reads as more rather than as a clip.

**Status glyph (16 x 16 svg).** A ring of radius 6.25 with a 1.5px stroke, centred at 8,8. Queued: the ring becomes a dotted run (dash `2 2.9`). Running: the ring is solid at ink 16% and an arc (quarter circle from 12 o'clock to 3 o'clock, stroke 1.5, round caps) in the accent turns once every 1.1s, linear, infinite. Stalled (running past 20s): the arc stops and sits at 55% opacity, so nothing spins forever. Done: the ring is green `#5fc284` (dark) or `#23884a` (light), and a check (`M5.1 8.3l2 2 3.8-4.1`, stroke 1.7) draws in with pathLength over 360ms after an 80ms delay. Failed: the ring is red `#f07c80` (dark) or `#c2353b` (light) and a cross (`M5.6 5.6l4.8 4.8M10.4 5.6l-4.8 4.8`) draws in the same way. The ring's dash and colour transition over 300 and 200ms, so the glyph morphs; it never swaps abruptly.

**Live duration.** While a call runs, the duration counts up each frame from 0 (`480ms` under a second, then `1.52s`), tabular figures so it never reflows. When it settles, it shows the recorded duration (or the observed one). Queued shows the word `queued`. A running call past 20s shows `still running`.

**Failure.** The block is a labelled group (`bash error output`), not an alert: a failure the line mounts with is history. Its first row holds a micro label `stderr`, then `last 4 of 6 lines` (mono 10.5px, uppercase, 18% tracking, faint; the count hides below a 448px container and truncates rather than wraps), and a ghost Retry button at the right: 28px tall, 7px radius, a 1px ink border at 15%, a 4% ink fill, a 14px retry arrow icon and the label in mono 12px, with an invisible 8px hit extension so the touch target clears 44px. A controlled call (`status` set) with no `onRetry` hides Retry, since only its host can change its status. Below it, 10px down, the last four stderr lines in mono 12px, leading 1.6, ink at 85%. An error tail is read, not scanned: below a 448px container it wraps (`pre-wrap`, breaking long words); from 448px it keeps one line per row and scrolls sideways with the edge fade. Retry sits beside the error it answers, so the block stays short. Clicking it sets the status to running, then to done (or failed on rejection) when the component owns its status. While the retry runs the block stays put: the stderr text dims to 45%, the arrow turns once every 0.9s and the label reads `Retrying` in the same width (both labels share one grid cell), so the line never changes height until the call settles. Once it lands done, the block holds for 480ms (dimmed, Retry disabled) so the drawn check registers in place before the line closes up. The `stderr` label itself is in the error colour so it separates from the count beside it.

**Expanded panel.** Arguments: a micro label, then a `pre` in mono 12px, leading 1.7, on a 10px-radius tint of the accent (7% fill, 16% inset hairline) with 14px horizontal and 12px vertical padding. The tint sits on a wrapper so the edge fade never fades the fill. Keys sit in the muted tone, strings in the accent, numbers and literals at ink 80%. Result: a micro label `Result` at the left and `N lines` at the right. Six lines show in a 10px-radius panel at ink 3% with a two-column gutter (right-aligned line numbers at ink 25%, `aria-hidden`, text at ink 75%); long lines scroll sideways inside the panel. A text button below (muted, ink on hover, its hit area extended 14px top and bottom and 8px at the sides) reads `Show 39 more lines` and then `Show fewer lines`. The full result is in a region capped at 184px (about nine lines, so a cut line hints that it scrolls), scrollable, focusable with a visible focus ring. An empty result says `No output was captured.`

**Typography.** Everything is mono except the words in micro labels, which are mono 10.5px uppercase, tracking 0.18em. Tool name 13px/500. Summary and duration 12px. Result and JSON 12px at leading 1.65 and 1.7. No serif, no display sizes: this is a log.

**Colour (dark / light).** Stage `#000000` / `#f4f4f5`. Surface `#0d0d0f` / `#ffffff`, with an inset 1px white/7% edge and a deep shadow `0 40px 80px -40px rgba(0,0,0,0.9)` on the stage card. Ink `#ededef` / `#17171a`. Hairline `rgba(255,255,255,0.08)` / `rgba(17,17,19,0.09)`. Queued `rgba(237,237,239,0.42)` / `rgba(23,23,26,0.42)`. Success `#5fc284` / `#23884a`. Error `#f07c80` / `#c2353b`. Accent default `#ff9d5c`; in light theme the accent is darkened 30% toward black for text and the arc (`color-mix(in oklab, accent 70%, #000)`). Secondary text uses two solid per-theme tokens rather than an alpha of ink, so it holds WCAG AA on every fill it meets (surface, hover, error tint, argument tint): muted `#98989a` / `#5d5d5f` for the summary, duration, JSON keys and Show more, and faint `#88888a` / `#68686a` for micro labels, the card header and the chevron. Only the decorative index and line numbers stay fainter, and they are `aria-hidden`. Hover on the header row is ink at 3.5%; press is ink at 5% with a 0.995 scale.

**Motion.** Expansion animates height from 0 to auto with opacity over 320ms on `[0.22, 1, 0.36, 1]`, and collapses over 200ms on `[0.4, 0, 1, 1]`. The chevron turns over 220ms on the same ease-out. The glyph morphs as above. Failure appears with the same height reveal. On first view the card, its header and each line rise 10px out of a 6px blur, 60ms apart, over 560ms. Nothing else moves; the rows never bounce and no idle loop runs except the running arc. Reduced motion: height reveals become a 150ms opacity fade, the arc stops turning and the count still updates.

**Accessibility.** The header is a native `button` with `aria-expanded` and `aria-controls` pointing at the details panel. Its accessible name includes the status word (`Queued`, `Running`, `Still running`, `Done`, `Failed`) in visually hidden text. The glyph is `aria-hidden`. Each call has one visually hidden `aria-live="polite"` span that changes only on a transition (`read_file running`, `read_file done in 1.52s`, `bash failed`), never for the state the line mounts in. The failure block is a labelled group. The Retry button and the show-more button are native buttons with visible focus rings (2px, offset 2px, ink colour, focus-visible only). The argument, stderr and result boxes are focusable only when they scroll. Show more and Retry clear a 44px touch target. Hover affordances never hide anything on touch: every action is a button.

**Responsive.** The line works from 320px to 1920px. Below a 384px container the index hides; the summary takes the space. Compact density fits a dense log at 320px. The stage centres a card that is a 640px maximum column with 16px side padding on small screens and a fixed height (`min(680px, 100dvh - 3rem)`), so the card itself never resizes; its body is the column-reverse log, so an expanding line grows upward inside the card while the line being read stays put.

**Don't.** No chat bubbles, no avatars, no sparkle icons, no emoji, no spinner that never resolves, no coloured tool badges (every tool name is the same ink), no gradient, no glass blur on the row, no pills, no bounce. The accent does not appear anywhere except the running arc and the argument tint. Do not invent a result when none was given; say nothing rather than fake output. Do not let a long result grow the page: it scrolls inside its own region.

**Demo.** A `Call log` card labelled `billing-sync`, a fixed 680px tall, holding eleven calls. The log reads from the bottom like a terminal: the body is `flex-direction: column-reverse` with `overflow-y: auto`, so the newest call sits on the floor, earlier calls scroll off the top under a 32px mask fade, and an expanding call grows upward without moving the line being read. The DOM runs newest first, which is also the keyboard order. Calls 01 to 09 are done (git log, docs, web.search, read_file, sql.query, rg); 10 is `bash pnpm test billing`, failed with an AssertionError; 11 is `read_file src/billing/invoices.ts`, queued until the visitor shows attention (a pointer move, key, wheel or 4s), then running for 1.52s to done. Retry on 10 reruns it for 0.65s. When the Status control forces 11 to failed, its Retry reruns it locally for 0.65s until the control changes again. The card, its header and each line rise 10px out of a 6px blur, 60ms apart, newest first. The status control forces the newest call's state; the layout controls restyle every line.
