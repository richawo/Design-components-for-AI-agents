Build an agent’s commit as a single card, in React 19 + Tailwind v4 + `motion/react`. It is a slip, not a repository page: the subject, the files touched, three checks that roll from queued to running to passed, and Open PR, which stays quiet until the checks have passed. Dark first, monochrome, with green used only for a passed check and a line added. One accent, on Open PR.

**Code shape.** One file. Tokens (`PALETTE` to `--cmt-*`, `DEFAULT_ACCENT` `#f4f4f5`, `EASE` `[0.22, 1, 0.36, 1]`, `CHECK_GAP` 320). Then `stateAt`, `Micro`, `Mark`, `useChecks`, `AgentCommitCard`, and the demo default export. The card owns its status when uncontrolled. The demo holds status so Open PR and Re-run agree with Customize.

**Layout.** A card, max 480px on the stage, `rounded-[20px]`, overflow hidden. Four bands separated by hairlines. Head, padding 16px (20px from `@md`): agent micro label and the hash on one line, the subject, one sentence, the branch. Files: a micro label, then one row per file, path truncated, counts on the right. Checks: a micro label and Re-run on one line, then one row per check, a 14px mark, the name, and the state word on the right. Footer: Open PR, full width, 40px (44px on a coarse pointer), 11px radius. The stage centres the card, 12px side padding (32px from `sm`), top 32px (64px from `sm`). Nothing overflows: paths truncate, the subject wraps, the footer button is full width.

**The checks.** Three, in order: Typecheck, Registry, Preview. `useChecks` steps twice per check, 320ms apart: queued, then running, then passed, and the next check starts as the previous one passes. Six steps, so they finish at 1920ms. Re-run sets the status back to ready and bumps the run id, which starts the timers again. An opened card, and reduced motion, skip the roll and show every check passed. Open PR is disabled at 40% opacity until every check has passed. Once it has opened it keeps its weight and its label becomes `PR #482`; a second click does nothing.

**The mark.** 14px. Queued is an empty ring. Running is a 2px ring with the top edge in the pass green, spinning (700ms is the Tailwind spin; none under reduced motion). Passed is a pass-green disc with a 2px check. The state word cross-fades and rises 4px over 200ms. Passed words are green. Running words are ink. Queued words are muted.

**Typography.** Subject: 17px, medium, tracking −0.02em, leading snug, `text-balance`. Detail: 13.5px, leading 1.45, body colour, max 46ch. Branch: mono 11.5px, muted. Paths: mono 12.5px. Counts: mono 12px, tabular. Check names: 14px. State words and Re-run: mono 11px. Hash: mono 12px, tabular, muted. Open PR: 14px, medium, tracking −0.01em. Micro labels: mono 10.5px, uppercase, tracking 0.16em, faint, normal weight.

**Colour (dark / light).** Surface `#0d0d0f` / `#ffffff`. Ink `#ededef` / `#17171a`. Body `#c6c6cc` / `#3f3f46`. Muted `#98989a` / `#5d5d5f`. Faint `#88888a` / `#68686a`. Hairline `rgba(255,255,255,0.08)` / `rgba(17,17,19,0.09)`. Hover `rgba(255,255,255,0.045)` / `rgba(17,17,19,0.045)`. Pass `#5fc284` / `#1d7a40`, used for a passed mark, the word Passed, and the added-line count. Deletions stay muted. Shadow: inset 1px edge, a top sheen on dark, and `0 40px 80px -40px`. Accent default `#f4f4f5`, mapped through `isInk` to the theme ink, so Open PR is white on dark and near-black on light. `inkOn` (relative luminance 0.62) picks the label when the accent is chromatic. The check on the green disc is `#06210f`. Stage `#000000` / `#f4f4f5`.

**Motion.** Head, files, checks and the button rise 10px out of a 6px blur over 500ms, delays 40, 120, 200 and 280ms. The filter clears at rest. State words swap as above. Press scales Open PR to 0.98 for 90ms. The running mark spins; nothing else loops. Reduced motion: 150ms opacity, no rise, no blur, no spin, checks already passed.

**Accessibility.** The root is a section named “Commit by {agent}”. The subject is an `h2`. Files are a list. Checks are a list. Re-run and Open PR are buttons. The marks are `aria-hidden`; the state is the visible word. A polite live region announces a re-run and an opened pull request after the click, not the roll itself and not the state the card mounted in. Focus-visible is a 2px ink outline, offset 2px. While checks are still running, Open PR has `cursor-not-allowed` and no hover.

**Responsive.** Fluid from 320 to 1920. The card caps at 480px. Type does not shrink. Open PR grows to 44px on `pointer-coarse`.

**Don’t.** No avatars, no GitHub logo, no rainbow file icons, no sparkle, no “AI” badge. Don’t enable Open PR while a check is queued or running. Don’t use green for the button. Don’t leave the spinner running under reduced motion.

**Demo.** Ada, hash `c4e19a2`, branch `pricing-faq`, subject “Name when the seat credit lands”. Three files. The script presses Re-run, waits for Typecheck, Registry and Preview to pass, then presses Open PR. The button reads `PR #482`.
